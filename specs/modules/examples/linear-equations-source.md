# Linear equations: original specification fixture

This original teaching fixture is supplied only to demonstrate Aristotle's external-agent handoff. It is not a supplied school textbook or a complete statement of England's curriculum.

<a id="equality"></a>
## Equality and balanced operations

An equation states that two expressions have equal values. Adding or subtracting the same number on each side preserves equality. Multiplying or dividing both sides by the same nonzero number preserves equality.

<a id="inverse-operations"></a>
## Solving a two-step linear equation

To solve 3x + 5 = 20, subtract 5 from both sides to obtain 3x = 15. Divide both sides by 3 to obtain x = 5. Substitution checks the answer: 3 × 5 + 5 = 20.

For a·x + b = c with a nonzero, x = (c - b) / a. This family has exactly one solution. Applying an operation to only one side generally changes the equation's solutions.

<a id="practice-domain"></a>
## Initial practice domain

Use integer coefficients a from 1 through 9, constants b from 0 through 20, and integer solutions s from 0 through 12. Construct c = a·s + b. This produces 2,457 parameter tuples. Zero solutions and a coefficient of one are valid. Negative coefficients, fractions as coefficients and unknowns on both sides are outside this initial family.

<a id="assessment"></a>
## Assessment and independent practice

For a final-answer-only item, award one mark when the submitted supported rational number satisfies the equation. Equivalent forms such as 5, 5.0 and 10/2 are accepted when the prompt does not restrict the answer form. An undefined number such as 1/0 cannot be graded as a valid answer. A final answer alone does not show which solving method was used.

A balance diagram can illustrate the equality and the same operation on both sides. Seeing the solution is help. Afterwards, ask the student to solve a different equation without revealing the solution, and later to interpret a short word problem using the same method.
